# Product Marketing Playbook, Competitive Battlecards, Talk Tracks, Website IA, Sign-Up/Onboarding Flows & UI Copy Deck (`detourrunclub.com` + `Detour Athletics LLC`)

## Goal
Create a complete, source-of-truth **Product Marketing & Positioning Playbook**—covering feature set definitions, competitive differentiation (`vs. Runna / Garmin / Static PDFs / Remote Coaches`), word-for-word talk tracks (for Cindy, club members, and prospective runners), and production-ready copy for **`detourrunclub.com` Information Architecture (IA), Sign-Up Flow (`/join`), Coaching Onboarding Flow (`/coaching-intake` $\rightarrow$ `/connect`), and the `/training` Web Application UI/UX**.

---

## Summary of Deliverables in This Plan

1. **Core Positioning & Value Proposition:**
   - **Detour Run Club Inc. (`501(c)(3)` Community · Always `$0` Dues · `#F4581C` Orange):** *"Different paces. Same detour. Effort over ego across every bridge, borough, and season."*
   - **Detour Athletics LLC (`1:1 Co-Pilot Coaching` · `#38BDF8` Cyan):** *"Algorithms don't run beside you on Saturday morning. We do."*
2. **Competitive Differentiation Battlecard:**
   - Head-to-head comparison against **Consumer Apps (Runna / Garmin Coach)**, **Static PDFs (Hal Higdon)**, and **Remote Online Coaches ($250–$350/mo)** across 6 axes: Side-by-Side Saturday Presence, Habit-Calibrated Paces, High-Touch Co-Pilot Adaptation, Chicago-Grade 8-Min Biomechanical Strength, 3 Personalized UI Lenses, and Off-Season / No-Race Benchmarking.
3. **5 Word-for-Word Talk Tracks:**
   - **Talk Track A:** Pitching Athlete #1 (Cindy) over coffee / text.
   - **Talk Track B:** The 30-second Saturday Bag-Drop elevator pitch for DRC regulars.
   - **Talk Track C:** For the runner with *no* race on the calendar (*Zero-Stress Workout Benchmarking + 7-Distance Estimator*).
   - **Talk Track D:** For the runner burned out by Runna or bored by Hal Higdon.
   - **Talk Track E:** Answering *"Is Detour Run Club still 100% free?"* (501(c)(3) vs. LLC clarity).
4. **Website IA (`detourrunclub.com`) & 4-Step Sign-Up $\rightarrow$ Onboarding Copy Deck:**
   - `/join` (Free Runner Passport) $\rightarrow$ `/training` (Interactive Preview & 4-Tab Hub) $\rightarrow$ `/coaching-intake` (Lens preference, Benchmark preference, Check-In cadence, PAR-Q+) $\rightarrow$ `/connect` (1-Click Strava + Garmin sync).
5. **Interactive Tab 4 (`📣 4. Product Marketing & Talk Tracks`) inside `/training.html` + Canonical `detour-web/docs/PRODUCT_MARKETING_AND_TALK_TRACKS.md`.**
